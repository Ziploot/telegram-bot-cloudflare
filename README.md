[![ZipLoot.app](https://img.shields.io/badge/Powered%20By-ZipLoot.app-818cf8?style=for-the-badge&logo=rocket)](https://ziploot.app)

A ready-made, serverless Telegram bot template that runs 24/7 on Cloudflare Workers for $0.

## 🚀 1-Click Automated Setup (Windows, Linux, macOS)

Run the following command in your terminal to automatically install, deploy, and register your bot:

```bash
npx github:Ziploot/telegram-bot-cloudflare
```

## 🛠️ Requirements
- Node.js installed (v18+)
- Cloudflare Account
- Telegram Bot API Token from [@BotFather](https://t.me/BotFather)
